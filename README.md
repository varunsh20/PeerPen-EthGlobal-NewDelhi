PeerPen is a blockchain-based application designed to verify the integrity, originality, and safety of text documents in a secure and transparent manner. Users can upload text files (e.g., .txt, .md) to a decentralized storage system powered by the Walrus HTTP API, where documents are analyzed for plagiarism, summarized, and checked for malicious content using an AI model (Grok with Llama-3.3-70b). The platform leverages the Hedera network for secure transaction logging and Ethereum Sepolia for PYUSD-based subscription payments, ensuring trust and scalability. With a user-friendly interface built using React and Chakra UI, the application offers a free trial of two checks, after which users can subscribe via a 1 PYUSD payment to unlock unlimited checks, with subscription status stored locally for seamless access.This project addresses real-world problems in academic, professional, and creative domains by combating plagiarism and ensuring document security. In education, it helps institutions verify the originality of student submissions, reducing academic dishonesty. For content creators and businesses, it safeguards intellectual property by detecting copied material and protects users from malicious content, such as hidden scripts in documents. By decentralizing storage and verification, it eliminates reliance on centralized servers, enhancing data privacy and trust. The subscription model makes it accessible, while the blockchain integration ensures tamper-proof records, making it a robust solution for secure document validation in a digital age.
